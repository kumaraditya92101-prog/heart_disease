# Heart Disease Prediction ❤️

A Machine Learning web application that predicts the possibility of heart disease using a KNN model.

## 🚀 Live Demo

[Click here to use the Heart Disease Predictor](https://heart-disease-rskn.onrender.com)

## 🛠️ Tech Stack

- Python
- Scikit-learn
- KNN
- Pandas
- NumPy
- Joblib
- Streamlit
- Render

## 📂 Project Files

- `app.py` - Streamlit application
- `knn_heart_model.pkl` - Trained KNN model
- `heart_scaler.pkl` - Feature scaler
- `heart_columns.pkl` - Feature columns
- `requirements.txt` - Required Python packages
